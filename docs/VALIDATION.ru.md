# Проверки 2.4.3

Нативная сборка Debian 13 ARM64 прошла четыре CTest, включая реальные affinity/FIFO и проверку проводного интерфейса Pi 5. Проверены метаданные и содержимое runtime/SDK, отдельный CMake-потребитель извлечённого SDK собран с точной версией.

Установочные пакеты проверены как файлы; новую установку и длительный аудиопрогон этот выпуск не проходил. Числа задержки из датированных исторических отчётов не являются результатом 2.4.3. Физический ADC/DAC-бэкенд не реализован.
