# Работа Pi 5 и выбор буферов

Новая установка 2.5.0 использует 8 входов, 8 выходов, 192 кГц, PCM24 и 32 capture frames. Физические каналы задаются на устройстве:

```sh
sudo piaoip-configure --inputs 8 --outputs 8 --restart
```

Windows получает эти значения через discovery. **Device → Channels** выбирает существующие каналы, не меняя физическую конфигурацию. Частота, разрядность, ASIO/LAN-буферы задаются в Windows. LAN принимает целые значения 0–2048. Автоподбора нет.

Все потоки AoIP на Pi 5 работают на CPU0. Отдельный `pi-aoip-lan.service` выбирает настроенный проводной интерфейс, запрашивает нулевую модерацию RX/TX, отключает EEE и назначает найденные IRQ Ethernet на CPU0. Он не меняет Windows и не отключает Wi-Fi/USB/Bluetooth/GPIO. Это не означает, что другие задачи ОС не используют остальные ядра. Если ethtool-параметр не поддерживается интерфейсом, смотрите журнал LAN-сервиса.

Сервис ждёт V3-подписку службы Windows или адаптера ASIO. При V3 и сокращении трафика передаются только выбранные каналы хоста; точный ноль может остановить аудиодатаграммы после трёх маркеров. Запущенная DAW продолжает получать ASIO callbacks. Stop снимает подписку, потерянная сессия истекает через три секунды.

## Измерения и настройки

В исторических тестах 2.3.1 на одной системе Pi 5 / Windows Intel I225-V два прогона по 180 секунд при ASIO64/LAN448 прошли без missing/late и deadline misses. RTT p50: 2,695/2,696 мс; p95: 2,768 мс; p99: 2,788/2,785 мс; max: 4,223/4,182 мс. Это синтетический цифровой круг, не ADC/DAC. Позднее для этого ПК проверялись другие буферы. Ни один результат не является универсальным значением по умолчанию.

Сначала найдите рабочий LAN при фиксированном ASIO, затем уменьшайте ASIO, сохранив LAN. Проверяйте профиль, длительность, p50/p95/p99/max, missing/late/deadline/overflow/TX expiry/errors и CPU под реальной нагрузкой DAW. Низкое среднее не доказывает стабильность.

Полная история: [проверки 29 сентября](VALIDATION-2026-09-29.ru.md). Текущий выпуск: [проверки 2.5.0](VALIDATION.ru.md). Сервис остаётся синтетическим PCM; физического ADC/DAC/I2S-бэкенда нет.
