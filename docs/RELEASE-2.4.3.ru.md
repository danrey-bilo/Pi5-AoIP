# Pi5-AoIP 2.4.3 — Raspberry Pi 5 runtime

Предварительный выпуск · `v2.4.3` · 2026-09-30

Сервис, метаданные пакетов и платформенная библиотека обновлены до 2.4.3 с совместимым транспортом. Новая установка использует 8×8, 192 кГц, PCM32; существующий профиль сохраняется. AoIP работает на CPU0, CPU2/CPU3 свободны от его потоков. Pi 5 использует аренду V3-сессий и ждёт ASIO start. Обновлены баннеры, метаданные репозитория и документация EN/RU.

## Установка

Установите `sudo apt install ./piaoip-rpi5_2.4.3-1_arm64.deb`, затем задайте Ethernet-адрес ПК: `sudo piaoip-configure --interface eth0 --peer YOUR_PC_IP --restart`. RT-ядро и IP ОС настраиваются заранее. Дополнительные SDK с закрытыми заголовками находятся в [закрытом релизе AoIP-lib](https://github.com/danrey-bilo/AoIP-lib/releases/tag/v2.4.3) для разработчиков с доступом. Для runtime доступ к этому репозиторию не нужен.

## Что проверено

Нативная сборка Debian 13 ARM64 прошла четыре CTest, включая реальные affinity/FIFO и проверку проводного интерфейса Pi 5. Проверены метаданные и содержимое runtime/SDK, отдельный CMake-потребитель извлечённого SDK собран с точной версией.

В рамках подготовки релиза MSI и новые DEB не устанавливались; работающий сервис Pi и профиль Windows не менялись. Новый длительный тест DAW и физический ADC/DAC не выполнялись. Сервис генерирует синтетический PCM, поэтому гарантированная задержка менее миллисекунды и аппаратный аудиотракт не заявляются.

## Лицензии

Личное некоммерческое использование бесплатно; коммерческое требует отдельной письменной лицензии. Для ASIO-компонента дополнительно действуют условия Steinberg.
